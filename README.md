# My Data analysis workflow with python 

## What is this repository?
This is a collection of reusable Python workflows for data analysis, statistical modeling and exploratory research.
Designed for students, researchers and analysts who want ready-to-run notebooks with explanations and reproducible workflows.

## Frameworks available
Framework | Description                                          | Status
----------|----------------------------------------------------- |-------
OLS       | Ordinary Least Square for Multiple Linear Regression | WIP
EDA       | Exploratory Data Analysis                            | planned

## Installation
### User 
1. Install VSCode
2. Install Python
3. open the project
4. Create virtual environment
5. Install requirements.txt
6. Insert Excel file
7. Execute Run All
